Coordinator dashboard

Who's signed up for what, read straight from the same demo store the signup page writes to — this is standing in for the "Monday check-in" box on the architecture diagram.

This dashboard and the signup page share one demo data store, so signups made on one show up here. It's a stand-in for the real thing — the architecture sketch shows Airtable filling this role for real. This shared store only persists within a Claude conversation; opened as a plain webpage (e.g. on GitHub Pages) it will show seed data only, and won't be shared between different visitors.
